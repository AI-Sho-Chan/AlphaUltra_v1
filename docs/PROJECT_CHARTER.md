# Project Charter — AlphaUltra_v1

## 目的（Why）
- TDNET/EDINET/価格・財務データから **3つのアルゴ（T5/T6/T7）** を実装・検証し、実運用可能な精度まで仕上げる。

## KPI（What）
- 2014年Q4テスト設定で:
  - **T5:** Purged/Embargo付きWF分割が再現可能（リーク0）
  - **T6:** OOF **AUC-ROC ≥ 0.60**（暫定目標、データ拡充と特徴強化で到達）
  - **T7:** **PPV≥0.8**のしきい値 `thr_ppv80` を算出できる（"none"ではない）

## スコープ（Scope）
- データ: Kabutan TDNET（2013-09-01〜）、J-Quants 価格・財務（最長取得）、Stooq/YF/EODHDは補助。
- 特徴: TDNETイベント、as-of財務（四半期）、価格派生（ret/vol）、イベント集約（3/5/10/20d）、比率/ログ安定化。
- モデル: LGBM（小規模グリッド＋不均衡対策）、Isotonic校正（PPV≥0.8）。

## 現状サマリ（2025-09-14）
- バックフィル：J-Quants財務 parquet ≈ 2,900+、as-of正規化 **rows≈125k / tickers≈2,955**（ログ参照）。
- T6 OOF AUC：一時最大 **~0.56**（母集団変動あり）。直近は **~0.19–0.51** 帯で推移。データ増で改善見込み。
- T7：PPV閾値は増分に応じて自動再評価。

## リスク/前提
- J-Quants APIのレート制限（429）：**単一プロセス運転＋クールダウン**で回避（最大300s）。
- データ密度が低い期間はAUCが不安定/Null。→ バックフィル継続で改善。
